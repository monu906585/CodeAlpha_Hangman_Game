# 🎮 Hangman Game – CodeAlpha Internship

## 📌 Project Overview
This project is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

The player must guess a hidden word one letter at a time. The game randomly selects a word from a predefined list of five words. The player is allowed a maximum of six incorrect guesses.

## 🚀 Features
- Random word selection from a predefined list
- Letter-by-letter word guessing
- Maximum of 6 incorrect attempts
- Displays correctly guessed letters
- Tracks previously guessed letters
- Prevents repeated guesses
- Validates user input
- Win and lose conditions

## 🛠️ Technologies Used
- Python 3
- Random module
- Loops
- Conditional statements
- Lists
- Strings
- User input and output

## 🎯 How to Play
1. Run the Python program.
2. The game will randomly select a hidden word.
3. Enter one letter at a time.
4. Correct guesses reveal the letters in the word.
5. Incorrect guesses increase your mistake counter.
6. You have 6 incorrect guesses to find the word.
7. Guess the complete word to win!
